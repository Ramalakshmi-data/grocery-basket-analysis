Dark Store Shelf Planner

Which grocery categories get bought together, and an interactive planner that puts them in the same aisle.

Python · Vanilla JS · Clustering · WCAG AA

I analysed 8,902 grocery order lines from 100 customers to answer a practical question: which categories get bought together, and how should a dark store lay out its aisles so pickers walk less?
